## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm

### Run Locally

```bash
git clone https://github.com/nishandhineePalanivel/Portfolio.git
cd Portfolio/portfolio_github
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
```

### Deploy to Vercel

```bash
npm install -g vercel
vercel
```
